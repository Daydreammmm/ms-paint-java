TYPE     : USER STORY US3.017 : mallasus : Finished
NAME     : Keyboard Shortcut Accessibility Controls
PRIORITY : 3
ESTIMATE : 1 days   ACTUAL : 1 days
AS A     : user with limited motor control or someone who prefers faster interaction
I WANT   : To control the paint application using keyboard shortcuts instead of mouse interaction.
This feature should allow core painting functions to be performed efficiently through keys alone.
Specifically:
    Undo → Ctrl + Z
    Redo → Ctrl + Y
    Delete → Delete
    Increase/Decrease Stroke Size → + / –
    Change Mode (Fill/Outline) → M
SO THAT  : users with motor impairments (e.g., ALS, hand tremors, limited hand movement) can still
fully use the application, and other users who prefer keyboard-based interaction can work faster
and more efficiently.
